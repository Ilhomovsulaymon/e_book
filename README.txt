MOBILE_BOOK PRO
1. ZIP arxivni oching.
2. mobile_book_pro papkasini VS Code orqali oching.
3. index.html faylini Live Server bilan ishga tushiring.
4. Internet yoqilgan bo‘lsa Google Fonts va kitob muqovalari yuklanadi.

FUNKSIYALAR:
- Kitoblarni qidirish (nom, muallif, kategoriya)
- Kategoriyalar bo‘yicha filtrlash
- A-Z / Z-A saralash
- Kitob haqida modal oyna va manba havolasi
- Sevimlilar (localStorage)
- Profil nomini saqlash (localStorage)
- Mobil menyu va responsive dizayn

ESLATMA:
Bu frontend demo. Haqiqiy ro‘yxatdan o‘tish, admin panel, server bazasi va buyurtma tizimi uchun backend/API ulash kerak.
Kitob havolalari tashqi manbalarga olib boradi; mavjudligi va foydalanish huquqlarini alohida tekshiring.
